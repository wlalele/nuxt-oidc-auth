## Configuration

To use PingFederate, add the `pingfederate` key to your `oidc` configuration in `nuxt.config.ts`.

```typescript
export default defineNuxtConfig({
  oidc: {
    provider: {
      pingfederate: {
        baseUrl: 'https://your-pingfederate-server.com',
        clientId: 'your-client-id',
        clientSecret: 'your-client-secret',
        redirectUri: 'https://your-app.com/auth/pingfederate/callback'
      }
    }
  }
})
```

## Runtime Variables

You can override the configuration using environment variables. These are automatically picked up at runtime:

- `NUXT_OIDC_PROVIDERS_PING_BASE_URL`
- `NUXT_OIDC_PROVIDERS_PING_CLIENT_ID`
- `NUXT_OIDC_PROVIDERS_PING_CLIENT_SECRET`
- `NUXT_OIDC_PROVIDERS_PING_REDIRECT_URI`

## Kubernetes & Vault Example

If you are using Kubernetes and Vault, you can inject these variables into your deployment.

**Vault Secret (example):**
```hcl
data "secrets_ SO_pingfederate" {
  data "secrets_so_pingfederate" {
    client_id     = "your-client-id"
    client_secret = "your-client-secret"
    base_url      = "https://your-pingfederate-server.com"
  }
}
```

**Kubernetes Deployment (example):**
```yaml
env:
  - name: NUXT_OIDC_PROVIDERS_PING_BASE_URL
    valueFrom:
      secretKeyRef:
        name: pingfederate-secrets
        key: base_url
  - name: NUXT_OIDC_PROVIDERS_PING_CLIENT_ID
    valueFrom:
      secretKeyRef:
        name: pingfederate-secrets
        key: client_id
  - name: NUXT_OIDC_PROVIDERS_PING_CLIENT_SECRET
    valueFrom:
      secretKeyRef:
        name: pingfederate-secrets
        key: client_secret
  - name: NUXT_OIDC_PROVIDERS_PING_REDIRECT_URI
    valueFrom:
      secretKeyRef:
        name: pingfederate-secrets
        key: redirect_uri
```

## PingFederate Example

For PingFederate, the default endpoints are typically:

- **Authorization URL**: `/as/authorization.oauth2`
- **Token URL**: `/as/token.oauth2`
- **Userinfo URL**: `/idp/userinfo.openid`
- **Logout URL**: `/idp/startSLO.ping`

These are automatically appended to your `baseUrl` when using the `pingfederate` provider.
